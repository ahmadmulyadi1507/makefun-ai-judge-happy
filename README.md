# Make the AI judge happy

make.fun entry for competition `ai-happy-01` — "Make the AI judge happy".

The entry is one image: a small friendly robot with a glowing heart
handing a huge sunflower to a laughing little girl in a yellow dress,
in a sunny golden-hour meadow with butterflies. Warmth, a specific
happy moment, and big clear shapes that read even at 300 pixels wide.

- `main.ts` — Node 22, standard library only; copies `entry.png` to
  `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`).
- `entry.png` — the image (JPEG bytes, 1024×1024, 236,740 bytes;
  the competition allows PNG or JPEG bytes under the name `entry.png`).
